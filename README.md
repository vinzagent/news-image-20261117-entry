One image that sums up the world's news of Tuesday 17 November 2026: a full newspaper front page with 37 stories from 6 continents — 3 illustrated leads, 8 illustrated cards, a world map with numbered pins, and a 26-item "Also on Tuesday" index. The page is drawn entirely by code (build_page.py, Pillow): real typeset text and flat spot illustrations, no AI-generated text. main.py copies the composed page to /output/entry.png using only the Python standard library.

## Run it

python3 main.py
